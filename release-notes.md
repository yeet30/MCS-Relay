## MCS-Relay 1.0.4

### New
- **Create a server step by step**: give it a name, start a new server or use a server folder you already have, choose where it lives on your PC (by default `MCS-Relay Servers` in your user folder), and set playit.gg and memory. Nothing is created until the last step.
- **Download a server** from its official source while creating one: vanilla, Paper or Fabric, any version from 1.2.5 on. The app checks the download and tells you which Java it needs, with a link if yours is too old.
- **Playing without playit.gg**: the app shows your PC's address on your home network, right under the server name, for friends on the same Wi-Fi.
- **The taskbar logo** now shows who is hosting, like the title bar and the tray: torches off, lit while you host, all three lit while someone else hosts.
- A short tour after your first server shows where your servers and their settings are.
- "Drive Folders" in the settings menu is now called **Servers**.

### Fixes
- Deleting your last server shows the Create / Join screen again, instead of the deleted server.
